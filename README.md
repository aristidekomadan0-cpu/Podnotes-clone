# Podnotes Clone 🎧✍️

Application gratuite inspirée de Podnotes : transcription audio, résumé et fiches de révision.

## 🚀 Stack utilisée
- **Frontend** : Next.js (React, interface responsive)
- **Backend** : Node.js + Express (API pour upload audio et gestion des notes)
- **Base de données** : Supabase (Postgres gratuit + authentification + stockage)
- **Transcription audio** : OpenAI Whisper (modèle open source)
- **Résumé automatique** : Hugging Face BART (facebook/bart-large-cnn)
- **Hébergement** : Vercel (frontend), Render/Railway (backend)
